# LICENSES/ — 벤더링된 라이선스 사본

이 디렉터리의 NEPLv1 텍스트는 **사본**이다. 정본과 생성기는 별도 저장소에 있다.

    https://github.com/newsniper-org/ethical-public-license   (공개)
    로컬: ~/ethical-public-license/
        NEPL-v1.{ko,en,ja,de}.{md,txt,rst,typ}
        templates/APPLICATION-NOTICE.{ko,en,ja,de}.txt
        tools/render.py

**현재 사본의 판: 초안 제2고 (2026-09-19).** 아직 freeze 전이므로 문면이 바뀌면 다시 가져온다.

여기에 사본을 두는 이유는 NEPLv1 **제3.2조**(배포물에 라이선스 사본과 적용 고지를 포함한다) 때문이다.
**여기서 고치지 않는다** — 문면을 바꿀 일이 있으면 템플릿 저장소에서 고치고 사본을 다시 가져온다.

    cp ~/ethical-public-license/NEPL-v1.*.{md,txt,rst,typ} LICENSES/
    # 또는 공개 저장소에서 직접 내려받는다

이 저장소의 적용 고지는 최상위 `LICENSE` 파일이다.

형식이 넷인 것은 편의일 뿐이다 — 제12.1조는 문서 형식을 전혀 규정하지 않는다.
