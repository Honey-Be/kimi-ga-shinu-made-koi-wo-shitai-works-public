# 두 시퀀스 — 대본·덱·연속 재생 데모

『きみが死ぬまで恋をしたい』(あおのなち / 一迅社)의 **비공식 2차 창작**. 결말의 두 시퀀스를 **연이어** 담는다 — 〈동귀어진 → 폭로방송〉과 〈「비창」 1악장〉. 각각의 **대본**(한국어 / 일본어)과, 그것을 touying 슬라이드로 옮겨 **배경음악 재생 위치에 맞춰 강조하는 웹 데모**, 그리고 **인물관계도 도표**가 있다.

> 이것은 팬이 쓴 구상이다. 원작의 공식 자료가 아니고, 원작자·출판사의 승인이나 후원을 받지 않았다.
> 원작에 관한 모든 권리는 원작자와 출판사에 있다.

## 음원 셋을 자르지도 이어붙이지도 않는다

세 곡이 차례로 온다.

| 0 | 드보르자크 〈어머니가 가르쳐 주신 노래〉 Op.55-4 | 0:00.0 | 3:42.0 |
| 1 | **무음 — 가안** | 3:42.0 | 3:21.9 |
| 2 | 브람스 『독일 레퀴엠』 Op.45 제5곡 | 7:03.9 | 6:52.2 |
| 3 | **무음 — 가안** | 13:56.1 | 1:36.3 |
| 4 | 차이코프스키 교향곡 6번 1악장 | 15:32.4 | 18:29.1 |

**총 34:01.5.** 코덱이 서로 달라(AAC / FLAC / AAC) 하나로 합치려면 최소 한 번은 재인코딩해야 하는데, **구상의 조건이 「전혀 자르지 않고 통째로」**이므로 **파일을 건드리지 않는 쪽**을 골랐다. `ffmpeg` 로 잇지 않는다 — 대신 `movements.json` 이 전역 시각만 주고, 브라우저가 그것을 보고 `<audio>` 의 `src` 를 갈아 끼운다. 무음 구간에서는 `<audio>` 가 멈추고 가상 시계가 돌며, 그동안 **다음 곡을 미리 걸어 둔다.**

**무음 구간의 길이는 구상에 없다.** 생성기가 글자 수에 비례해 정한 **가안**이며(비트당 10–30초, 두 언어의 최대값), 화면의 타임라인에서 **빗금 친 보라색 띠**로 구분된다.

## 데모가 하는 일

전역 시각 → 비트 이분탐색 → 덱 페이지 교체. 동기 표의 원천은 **덱 자신**이다 — 각 비트 페이지에 Typst 메타데이터

```typst
#context [#metadata((page: here().page(), beat: 26, t_sec: 420.0, track: "brahms5", …)) <sync-beat>]
```

를 심고, fork 가 `--query-label sync-beat` 로 그것을 모아 `manifest.json` 에 페이지별로 붙인다. 별도의 sync.json 이 없다.

폰에서는 슬라이드 글자가 작아 읽을 수 없으므로, 각 비트의 **전문**을 메타데이터에 함께 실어 목록에서 현재 비트만 펼친다. 「크게 보기」는 전체화면 API 가 되면 그것으로, 안 되면 CSS 오버레이 + 세로 화면에서 덱 90° 회전.

키: `Space` 재생·정지 · `←/→` 비트 · `[ / ]` 구간 · `M` 악장 · `L` 언어 · `Z` 크게 · `Esc` 닫기.

### 쓰는 법

```sh
just demo-setup audio_dv="/path/dvorak.m4a" \
                audio_br="/path/brahms5.flac" \
                audio_tc="/path/pathetique.m4a"   # 주지 않은 곡은 건너뛴다
just demo-slides    # 두 대본 → 덱 + 악장표 → typst 79쪽 확인
just demo-build     # Astro 빌드 (integration 이 덱을 SVG 로 내보낸다)
just demo-check     # manifest ↔ 두 대본 ↔ 악장표 대조(오래된 덱 검출 포함)
just demo-e2e       # playwright — 악장 전환·무음 시계·스크러버·모바일 세로/가로
just relations      # 인물관계도 .typ 다시 생성
```

**음원은 이 저장소에 없다.** 세 작곡가 다 공유저작물이나 *녹음*은 아니다 — 권리 확인 전에는 넣지 않는다. 각자 자기 사본을 쓴다(이 데모가 쓴 것은 카라얀/베를린 필하모닉 18:29.1 · 노링턴 6:52.2 · 첼로와 기타 편곡 3:42.0).

## 이 저장소에 없는 것

이것은 더 큰 비공개 작업 저장소의 **공개용 스냅샷**이다. 다음은 담기지 않았다.

- **원전** — 결말 구상 통합 문서와 동반 문서, 프리퀄, 비교분석
- `proposals/` (판본별 제안·결정 기록), `briefs/` (작업 규칙 요약), `index/`
- 대본의 `check.md`(정합성 검사)와 `JUDGMENT.md`(판정 기준)
- 작업 규칙 문서(CLAUDE.md·HANDOVER.md)와 해시 매니페스트

그래서 여기 있는 파일이 **`원전`·`proposals/P65`·`P68`·`P70`·`check.md`·`docs/kimishinu_merged_…` 를 가리키는 곳이 있다.** 그 참조는 비공개 저장소를 가리키며, 일부러 함께 싣지 않았다 — 대본 문면은 검사 당시 그대로 두는 편이 낫다고 보았다. 대본이 괄호로 적는 **행 번호**도 그 비공개 원전의 것이다.

## 대사에 관하여

**대사의 문면은 전부 구상의 것이지 원작자의 것이 아니다.**

- **12번 시퀀스** — 확정 문면은 셋뿐이다: 마법의 문구 셋, 유언 네 항목, 그리고 에이란의 마지막 한 마디. **셋 다 구상 원전에 이미 있던 것**이고, 대본이 새로 지어낸 대사는 **0**이다.
- **11번 시퀀스** — 원전 큐 표가 적은 *내용*을 말로 옮긴 것이며, 문면은 2026-09-18에 구상자가 정했다.
