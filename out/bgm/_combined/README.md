# _combined — 두 시퀀스를 연이어 보는 덱

**공개용 스냅샷에 실린다**(2026-10-08, 제안자가 공개 범위를 넓혔다). 12번(동귀어진 → 폭로방송)과 11번(〈비창〉 1악장)을 **하나의 touying 덱**으로 잇고, `web/pathetique-sync/`의 Astro 데모가 **배경음악 재생 위치에 맞춰** 그 덱을 넘긴다.

**음원은 저장소에 없다.** 그리고 **자르지도 이어붙이지도 않는다** — 음원은 권리 확인 전에는 이 저장소에 넣지 않는다.

## 여기 있는 것 — 전부 생성물

| | |
|---|---|
| `slides_{ko,ja}.typ` | 두 시퀀스를 이은 덱. **손으로 고치지 않는다** |
| `movements.json` | **악장표** — 음원 셋과 그 사이 무음 구간의 전역 시각 |

`tools/sequence_demo_build.py gen` 이 만든다. 원본은 `out/bgm/12_…/script_{ko,ja}.md` · `out/bgm/12_…/cues.json` · `out/bgm/11_…/script_{ko,ja}.typ` 넷이며, **문장을 고치지 않고 그대로 옮긴다.**

## 악장표 — 재인코딩이 한 번도 일어나지 않는다

**ffmpeg 로 이어붙이지 않았다.** 세 음원을 하나로 합치려면 코덱이 달라(AAC / FLAC / AAC) 최소 한 번은 재인코딩해야 하는데, 제안자의 조건이 **「전혀 자르지 않고 통째로」**이므로 **파일을 건드리지 않는 쪽**을 골랐다.

대신 이 표가 전역 시각을 준다. 브라우저가 이 표를 보고 `<audio>` 의 `src` 를 갈아 끼운다.

**⚠ 무음 구간의 길이는 원전에 없다.** 생성기가 **글자 수에 비례해**(비트당 10–30초, 두 언어의 최대값) 정한 **가안**이며, 덱과 화면에 그렇게 적는다. 바꾸려면 `tools/sequence_demo_build.py` 의 `SILENT_MIN/MAX/CPS` 를 고치고 `just demo-slides` 부터 다시 한다.

`just demo-setup` 이 **그대로 복사**한다(변환 없음). `web/pathetique-sync/public/audio/` 는 `.gitignore` 대상이다.

## 순서

```
just demo-setup     # submodule · venv · pnpm · 음원 셋 복사
just demo-slides    # 대본 넷 → slides_{ko,ja}.typ + movements.json, typst 로 85쪽 확인
just demo-build     # Astro 정적 빌드 (덱 내보내기 포함) → web/pathetique-sync/dist
just demo-check     # manifest ↔ 대본 ↔ 악장표 대조
just demo-e2e       # playwright 헤드리스 검증 (악장 전환·무음 시계·스크러버 포함)
just demo-dev       # 개발 서버
```

## 화면

- **전역 스크러버** — 아래의 띠가 악장이다. 갈색이 음원, **빗금 친 보라색이 무음(가안)**.
- **목록** — (시퀀스 · 구간)이 바뀌는 자리마다 머리글. 현재 비트는 전문을 펼친다.
- **키** — `Space` 재생·정지 · `←/→` 비트 · `[ / ]` 구간 · **`M` 악장** · `L` 언어 · `Z` 크게 · `Esc` 닫기.
- 무음 구간에서는 `<audio>` 가 멈추고 **가상 시계**가 돈다. 그동안 **다음 곡을 미리 걸어 두므로** 무음이 끝나면 곧바로 들어간다.

## 앞 판의 것

`out/bgm/11_비창_1악장_시퀀스_대본/demo/` 의 `slides_{ko,ja}.typ` 는 **11번만 담던 앞 판의 덱**이다. Astro 앱은 더 이상 그것을 쓰지 않는다(이제 이 폴더를 본다). 지우지 않고 그대로 둔다 — `tools/pathetique_demo_build.py` 로 다시 만들 수 있으며, 그 파일의 파서는 지금도 `sequence_demo_build.py` 가 11번을 읽는 데 쓴다.
